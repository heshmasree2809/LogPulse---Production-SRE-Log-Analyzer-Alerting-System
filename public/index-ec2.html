SRE Component Architecture

Incident Monitoring Flow

Telemetry pipeline mapping each system component

1. NGINX REVERSE PROXY PORT 80

Serves static files directly from disk and reverse-proxies API calls to 127.0.0.1:8000. Logs client IP, method, status code, and $request_time.

2. FASTAPI / SAMPLE APP PORT 8000

Asynchronous ASGI backend running behind Uvicorn. Exposes business endpoints plus /health and /api/stats.

3. ANALYZE.SH (BASH) CORE PIPELINE

High-speed CLI parsing using grep | awk | sort | uniq -c for immediate command-line triage during production outages.

4. ANALYZE.PY (PYTHON) PERCENTILES

Parses access logs via regex, handles malformed records, and computes p50/p95 latency and slowest routes into JSON format.

5. ALERT.PY (WATCHDOG) CRON (5 MIN)

Reads the last 5 minutes of logs. If 5xx error rate exceeds the 5% threshold, it formats an alert payload and triggers AWS SNS.

6. AWS SNS & IAM ROLE PAGER ALERT

Dispatches notification emails to SRE on-call engineers. Authenticates via EC2 IAM Role credentials (IMDSv2) with zero static access keys.
